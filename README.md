# dsh-kanban-board

DSH-плагин: канбан-доска распределения задач между воркспейсами реалма, а не между сессиями одного
воркспейса. Механизм описан в docs/PROTOCOL.md; обоснование и модель — docs/ANALYSIS.md.

Это репозиторий плагина, а не оркестратор конкретных проектов: список воркспейсов задаёт конфиг реалма,
который владелец кладёт в свой воркспейс-архитектор (пример — examples/realm.example.json).

## Состав

- docs/PROTOCOL.md — контракт: карточка, переходы, письма, журнал, мотор, конфиг реалма
- docs/ANALYSIS.md — обоснование, слабые места, модель четырёх воркспейсов
- examples/realm.example.json — пример конфига реалма (console/proxy/optimizer)

## Установка

1. package.json — манифест плагина: dsh.profile.bundles (host-половина) и dsh.client.platform (вкладка).
2. Бандл в профиль DSH (~/.dsh/profiles/<профиль>/): зависимость и запись в манифест, симлинк в node_modules.
3. Перезапустить DSH; вкладка «Канбан» появляется в правом сайдбаре.

Точный формат манифеста — по референсу VictorKozachek/dsh-kanban (KANBAN.md, раздел установки).
